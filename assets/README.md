# 素材制作指南

桌宠的全部外观都来自 `assets/boss/` 目录下的序列帧 PNG。**程序不绑定任何形象**：把这个目录里的图换掉，桌宠就变成任何你想要的角色——你的猫、你的老板、一只史莱姆都行。缺失的动作组会自动回退到内置占位小人，所以素材可以一组一组慢慢补。

## 一、素材规格（硬性要求）

| 项目 | 要求 |
|---|---|
| 尺寸 | **128×128 像素**，正方形（其他尺寸会被自动缩放，但可能变形或模糊） |
| 背景 | **透明**（PNG Alpha 通道） |
| 命名 | `<动作>_<帧号>.png`，帧号从 0 开始连续编号，如 `walk_0.png`、`walk_1.png` |
| 朝向 | **统一画朝右**。向左的画面由程序水平镜像，不用画两份 |
| 位置 | 全部放进 `assets/boss/`，重启程序即生效 |

## 二、需要的 8 组动作

| 动作 | 文件名前缀 | 建议帧数 | 画面内容 |
|---|---|---|---|
| 站立 | `idle` | 2–4 | 原地站立，帧间微小差异（眨眼、呼吸起伏）形成"活着"的感觉 |
| 走路 | `walk` | 4–6 | 行走循环：迈左腿→并拢→迈右腿→并拢 |
| 鞠躬 | `bow` | 3–4 | 站直→弯腰 45°→深鞠躬 90°（可加一帧回弹） |
| 睡觉 | `sleep` | 2 | 闭眼打瞌睡，两帧交替（头一点一点 / 冒 Zzz 气泡） |
| 被拎起 | `dragged` | 1–2 | 被抓住后领悬空，四肢下垂乱晃、表情惊慌 |
| 摔倒 | `land` | 2–3 | 屁股着地→坐在地上揉腰、头顶冒星星 |
| 端咖啡 | `coffee` | 4–6 | 双手端咖啡杯小步快走的循环（同 walk 但手上有杯子） |
| 庆祝 | `special` | 3–4 | 双手举高欢呼、撒彩带/比 OK 手势 |

共约 25–35 张。最少可用集：`idle` + `walk` 各 2 帧就能跑起来，其余先用占位图。

## 三、提示词模板（不含人名，可直接改角色）

### 1. 先定一张"角色设定图"

一致性是序列帧最难的部分。先生成一张满意的角色图，之后所有动作都基于它（各工具的做法见下文"保持一致性"）。

> Q版卡通角色设定，2.5头身，中年科技公司老板大叔，棕色短发微秃，黑色圆领T恤，牛仔裤，运动鞋，自信的坏笑，胸前有小火箭徽章，扁平插画风格，厚描边，纯色背景，全身正面图
>
> 英文（Midjourney 等）：chibi cartoon character sheet, 2.5 heads tall, middle-aged tech CEO uncle, short brown hair slightly balding, black crew-neck t-shirt, jeans, sneakers, confident smirk, small rocket badge on chest, flat illustration style, bold outline, solid background, full body front view

**换形象只改这一段的外貌描述**（比如换成"橘色圆脸猫，绿色眼睛，白色肚皮"），下面的动作提示词全部不用动。

### 2. 各动作提示词（在角色设定基础上追加）

生成时用"同一角色 + 动作描述 + 帧描述"，一次要一帧：

- **idle**：`同一角色，放松站立，双手插兜，正面微侧朝右` / 第 2 帧加 `闭眼眨眼瞬间`
- **walk**：`同一角色，侧面朝右行走，左脚在前迈步` → `双脚并拢` → `右脚在前迈步` → `双脚并拢`（4 帧循环）
- **bow**：`同一角色，侧面朝右，微微欠身 30 度，双手贴裤缝` → `弯腰 60 度` → `深鞠躬 90 度，表情诚恳冒汗`
- **sleep**：`同一角色，站着打瞌睡，闭眼，头歪向一侧` / 第 2 帧 `头点得更低，头顶冒 Zzz`
- **dragged**：`同一角色，被无形的手拎住后领悬在空中，四肢下垂，表情惊慌瞪眼`
- **land**：`同一角色，屁股着地摔坐在地上，腿朝前伸` → `坐在地上揉后腰，头顶冒小星星`
- **coffee**：`同一角色，侧面朝右小跑，双手端一杯冒热气的咖啡，表情殷勤`（4 帧同 walk 的腿部循环）
- **special**：`同一角色，正面双手举过头顶欢呼，笑容灿烂` → `跳起，周围撒彩带` → `落地比出双手大拇指`

### 3. 保持一致性的技巧

- **即梦/豆包**：上传第一步的角色设定图作参考图，或用"角色一致性/同一角色"功能，再输入动作描述
- **Midjourney**：用 `--cref <角色图URL>` 锁角色、`--sref` 锁画风；序列帧同批生成
- **通用**：所有帧放在同一个会话里连续生成；描述里重复关键外貌特征（黑T恤、棕短发）；画风关键词（扁平插画、厚描边）每次都带上

## 四、后期处理

1. **抠背景**：如果生成的不是透明背景，用 remove.bg、即梦自带抠图、或 PS/GIMP 魔棒去底
2. **裁切缩放**：裁成正方形（角色居中、脚底贴近下边缘——程序按贴地对齐），缩放到 128×128。批量缩放可用：
   ```
   magick input.png -resize 128x128 -background none -gravity south -extent 128x128 output.png
   ```
3. **命名入库**：按 `<动作>_<帧号>.png` 改名放进 `assets/boss/`
4. **验证**：运行 `python main.py`——哪个动作还是"占位小人 + 文字标签"，就说明那组文件名没对上或没放进来

## 五、常见问题

- **动画抖动/角色跳变**：帧之间角色比例不一致。回到第三步用参考图重生成，或只保留最像的帧（每组 2 帧也够用）
- **脚下悬空/陷进任务栏**：角色在画布里太靠上或太靠下，重新裁切让脚底贴近图片下边缘
- **想同时保留多套形象**：在 `assets/` 下建多个目录（如 `assets/cat/`），把 `main.py` 里 `SpriteSet(ROOT / "assets" / "boss")` 的目录名一改即可切换
