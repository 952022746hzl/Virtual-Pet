# 马斯克老板桌宠 🚀

Windows 桌面宠物：Q 版"马斯克老板"在你桌面上闲逛、鞠躬道歉、递咖啡、说"求你别扣我绩效"。纯本地运行，零 API、零联网。

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

将在托盘区显示，右键菜单即可控制。

## 玩法

### 点击互动
直接点击宠物，它会鞠躬并随机说一句台词（如"对不起，是我错了"、"求你别扣我绩效！"等）。

### 拖拽抛掷
鼠标拖住宠物拉动，松开后它会被抛出去。从高处扔下、落地速度够快（≥900 px/s）时会重摔（land 动画 + '哎呀！轻点扔'台词）；轻轻放下则正常落地。

### 站在窗口顶端
宠物会站在其他窗口的顶边，不会被其他程序遮挡，随时陪伴你工作。

### 托盘菜单命令
右键托盘图标打开菜单，可选：
- **要杯咖啡**：递上一杯咖啡，宠物会说"您的咖啡，趁热喝"
- **取消加班**：取消加班，播放"今晚不加班！都回家！"
- **返还扣薪**：返还扣掉的绩效，宠物会说"扣掉的绩效，双倍奉还！"
- **跟随鼠标**：勾选后，宠物会追逐你的鼠标光标（切换开关）
- **显示/隐藏**：快速隐藏或显示宠物窗口
- **退出**：关闭程序（这是唯一的退出方式）

### 自动睡觉与唤醒
宠物在 120 秒内没有被互动时会进入睡眠状态。点击它可立即唤醒，它会醒来后说一句"啊？！我没睡！我在思考火星殖民……"之类的话。

### 鼠标追踪
在托盘菜单中勾选"跟随鼠标"，宠物就会不断靠近你的鼠标光标，制造出在桌面上追逐的效果。

## 自定义台词

编辑 `quotes.json` 文件即可更换台词。每个场景 key 对应不同的互动情景：

- `click`：用户点击宠物时
- `coffee`：使用"要杯咖啡"命令时
- `cancel_overtime`：使用"取消加班"命令时
- `refund_salary`：使用"返还扣薪"命令时
- `wake`：宠物被唤醒时
- `land_hard`：宠物硬着陆时

每个 key 对应一个数组，程序会随机从中选择一句。示例：

```json
{
  "click": [
    "您辛苦了！",
    "对不起，是我错了。",
    "求你别扣我绩效！"
  ],
  "coffee": [
    "您的咖啡，趁热喝。",
    "老板亲自递的咖啡，还满意吗？"
  ]
}
```

## 换上你自己的素材

将 128×128 像素的透明 PNG 序列帧放入 `assets/musk/` 目录。文件命名格式为 `<动作>_<帧号>.png`，其中动作组包括：

- `idle`：站立（空闲状态）
- `walk`：行走
- `bow`：鞠躬
- `sleep`：睡眠
- `dragged`：被拖拽
- `land`：着陆
- `coffee`：喝咖啡
- `special`：特殊动作

例如：`idle_0.png`、`idle_1.png`、`walk_0.png`、`walk_1.png` 等。

**重要提示**：如果某个动作的文件缺失，程序会自动回退到内置的占位小人，确保程序不会崩溃。你可以逐步替换动作，甚至只替换部分动作。

## 用 AI 生成 Q 版素材

推荐使用以下 AI 工具生成 Q 版形象序列帧：

**提示词参考**（配合 Midjourney、即梦、豆包等）：

> 生成一个 Q 版卡通人物的动作序列帧。风格为极简可爱的 Q 版头身设定，头占比 40%，身体圆润。人物表情夸张喜感。
>
> 需要以下 8 类动作，每类 3-4 帧：
> 1. idle 站立：双手自然放下，面带微笑，目视前方
> 2. walk 行走：左右腿交替，手臂摆动，富有节奏感
> 3. bow 鞠躬：90 度鞠躬道歉，显得恭敬
> 4. sleep 睡眠：蜷缩或躺下，眼睛闭上，显得疲倦
> 5. dragged 被拖拽：身体拉长变形，显得无奈
> 6. land 着陆：双膝微曲，准备着陆姿态
> 7. coffee 喝咖啡：双手拿着咖啡杯，做出品尝的动作
> 8. special 特殊：做出惊喜或夸张的动作
>
> 所有帧背景透明，大小 128×128 像素，采用 PNG 格式。
